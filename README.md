# TravelAI Master - Private Agency Internal Tool

Este es un sistema multirepositorio para la gestión y generación de cotizaciones de viajes con Inteligencia Artificial.

## Estructura
- `/backend`: API en Node.js, Express, TypeORM y PostgreSQL. Integración con Gemini AI.
- `/frontend`: Aplicación SPA en React 18, Vite, TypeScript y Tailwind CSS.

## Requisitos
- Node.js v18+
- PostgreSQL
- Gemini API Key

## Instalación Rápida
1. Clonar el proyecto.
2. Entrar a cada carpeta (`backend` y `frontend`).
3. Ejecutar `npm install`.
4. Configurar los archivos `.env`.
5. Iniciar con `npm run dev`.

Desarrollado para Agencias de Viajes Premium.
